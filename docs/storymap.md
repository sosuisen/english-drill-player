# English Drill Player

「復習」は大事なのであえて一番最後のアクティビティに分けてある。

ファイル（ユニット）には複数のドリルが含まれるものとする。

ユーザータイプは「英語学習者」のみ。「先生」がいると有難いが・・。

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. 実際に利用可能
5. 苦手ドリルの練習強化
6. ドリル2周目以降の対応
7. 発音練習の強化

- 準備する #英語学習者
  - ドリルを登録
    - [x] 決められた音声フォルダで始める
      - [x] 音声フォルダを自由に1つ登録する
        - v 2つ目以降のフォルダを追加する
- ドリルを実行する #英語学習者
  - ドリルを探す
    - [x] ユニット一覧から探す
      - v 苦手なドリルから探す
  - ドリルを再生する
    - [x] ドリルの音声を最後まで再生する
      - [x] 現在再生中のドリルをリストで確認できる
        - [x] ^ ドリルをクリックすると、ドリル冒頭から再生できる
          - [x] ^ ひとつ前、ひとつ次のドリルから再生する
            - [x] ^ ユニットをダブルクリックすると、先頭のドリルから再生する
  - 再生を制御する
    - [x] v 一時停止、再開、停止できる
      - 再生速度を変えて、ゆっくりまたは速く聞く
- チェックする #英語学習者
  - 進度を確認する
    - [x] 最終再生日時を確認できる
      - v 苦手なドリルに苦手チェックを入れる
        - 終えたドリルに完了チェックを入れる
  - 発音を確認する
    - vvvv 自分の発音を録音し、手本の音声と聞き比べる
- 復習する #英語学習者
  - 前回の復習をする
    - [x] 前回終えたユニットを繰り返す
      - v 苦手チェックしたドリルを繰り返す
